# Projeto SQL — Biblioteca

Projeto desenvolvido para praticar consultas e manipulação de dados utilizando **SQL Server**.

## Objetivo

Criar um banco de dados de uma biblioteca e desenvolver consultas SQL para analisar informações sobre livros, autores, gêneros, notas, páginas, idiomas, anos de publicação e editoras.

## 🗃️ Estrutura do banco

A tabela `livros` contém 30 registros fictícios e as seguintes informações:

* ID
* Título
* Autor
* Gênero
* Nota
* Número de páginas
* Idioma
* Ano de publicação
* Editora

## 🛠️ Tecnologias

* SQL
* Microsoft SQL Server
* SQL Server Management Studio (SSMS)

## 📊 Consultas desenvolvidas

Durante o projeto foram praticados conceitos como:

* `SELECT`
* `WHERE`
* `LIKE`
* `ORDER BY`
* `TOP`
* `COUNT`
* `AVG`
* `MAX`
* `MIN`
* `GROUP BY`
* `HAVING`
* `BETWEEN`
* `IN`
* `AND`
* Subconsultas
* Funções de agregação

## Exemplos de análises

Entre as consultas desenvolvidas estão:

* Busca de livros por gênero;
* Livros com notas acima de determinado valor;
* Livros publicados a partir de determinado ano;
* Ordenação dos livros por avaliação;
* Quantidade de livros por gênero;
* Média de avaliação por gênero;
* Quantidade de livros por editora;
* Livros com avaliação acima da média geral;
* Os 3 livros mais bem avaliados publicados a partir de 2020.

## 📌 Observação

Os dados utilizados neste projeto são **fictícios** e foram criados exclusivamente para fins de estudo e prática de SQL.
